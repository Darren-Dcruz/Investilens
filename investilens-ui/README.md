# INVESTILENS ?
### AI-Powered Autonomous Investment Research & Decision-Support Agent

Built for the Hackathon with **Webcmd**, **Hermes Agent Framework**, **Google Gemini**, and **React + Tailwind CSS**.

---

## ?? Key Features
- **Deterministic Scoring Engine (Step 12)**: Explainable 7-dimension scoring model (Financial Health 25%, Growth 20%, Historical 15%, Valuation 15%, Debt 10%, News 10%, Risk 5%).
- **Multi-Source Evidence Locker (Step 5 & 6)**: Every claim cross-checked against Primary Source A and Independent Source B with confidence ratings and direct URL citations.
- **Human-in-the-Loop Decision Gates (Step 3 & 15)**: Visibly enforces approval checkpoints before web crawling and before generating final reports.
- **Active Bear Case & Disconfirmation (Step 11)**: Actively searches for reasons *NOT* to invest, guarding against LLM confirmation bias.
- **News Sentiment Intelligence (Step 8)**: Multi-article sentiment classification (Positive %, Neutral %, Negative %).
- **Hypothetical Allocation Model (Step 14)**: Capital-tailored asset breakdown with strict "Not Financial Advice / Decision-Support Only" compliance.
- **Dual-Engine Architecture**: Seamlessly switch between **Demo Simulation Mode** (for rehearsals & pitch demo) and **Live Hermes/Webcmd Bridge Mode**.
